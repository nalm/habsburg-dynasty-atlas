# 🦅 합스부르크 왕조 750년 가계도 아카이브 (1273–현재)

루돌프 1세(1273)부터 알브레히트계·레오폴트계 분기(1379), 막시밀리안 1세와 카를 5세의 세계 제국, 스페인·오스트리아 합스부르크 분파(1556–1740), 합스부르크-로트링겐 제국(1740–1918), 그리고 현대 가문 수장(오토·카를·페르디난트 즈보니미르)까지 **24세대 750년 합스부르크 왕조의 혈통·혼맥·근친혼·영토 변천**을 탐색하는 인터랙티브 역사 웹앱입니다.

## 주요 기능

1. **🌳 2D 시각 가계도 트리 (`VisualFamilyTree`) & 시대별 상세 카드 뷰 (`DynastyTreeView`)**
   - 1~24세대 세로 시간축 × 5개 분파(스페인 합스부르크 / 알브레히트계 / 황제 직계 본류 / 레오폴트·프란츠 카를 방계 / 티롤·내오스트리아 방계) 병렬 배치
   - 부모-자식 혈연선, 방계 제위 승계 점프 화살표, 근친 정략결혼 교차선 레이어 ON/OFF 토글
   - 인물 호버 시 직계 조상 ↔ 후손 혈통 줄기 하이라이트 및 8대 역사 분기점 북마크 이동
2. **🧭 혈연 · 제위 승계 경로 추적기 (`PathfinderView`)**
   - 임의의 두 인물 간 최단 혈연·혼맥 연결 경로 탐색(BFS) 및 5대 추천 역사 시나리오 프리셋
3. **🧬 근친혼(Pedigree Collapse) & 유전 분석실 (`InbreedingView`)**
   - 스페인·오스트리아 분파 간 9대 근친 결혼 루프 탐색기 및 세대별 근친교배 계수($F=0.025 \rightarrow 0.254$) 비교 차트
   - 카를로스 2세의 조상 압축 현상(Pedigree Collapse) 시각화
4. **📜 제국 연대기 & 영토 변천 타임라인 (`TimelineTerritoryView`)**
   - 정략결혼과 조약으로 확장·분할·해체된 6대 영토 판도 및 1273–1989 핵심 사건 타임라인
